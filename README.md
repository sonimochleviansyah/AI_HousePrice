# 🏠 AI House Price Prediction

Project Ujian Tengah Semester Artificial Intelligence.

Aplikasi prediksi harga rumah berbasis Machine Learning dan Deep Learning menggunakan Flask Web Application.

---

# 📌 Project Overview

Project ini bertujuan untuk memprediksi harga rumah berdasarkan karakteristik properti menggunakan beberapa algoritma Artificial Intelligence.

Dataset yang digunakan berasal dari Kaggle:

House Prices - Advanced Regression Techniques.

Project ini mengimplementasikan:

* Linear Regression
* Artificial Neural Network (ANN)
* Backpropagation
* Long Short-Term Memory (LSTM)
* K-Means Clustering

---

# 🧠 Algorithms Used

## 1. Linear Regression

Digunakan sebagai baseline model untuk prediksi harga rumah.

## 2. Artificial Neural Network (ANN)

Model deep learning untuk mempelajari hubungan kompleks antar fitur.

## 3. Backpropagation

Digunakan untuk optimasi bobot jaringan saraf.

## 4. Long Short-Term Memory (LSTM)

Digunakan untuk eksperimen deep learning berbasis sequential learning.

## 5. K-Means Clustering

Digunakan untuk pengelompokan data rumah berdasarkan karakteristik tertentu.
